Motyw GUI - projekt moda Fabric dla Minecraft Java 1.21.11

Sterowanie: prawy Shift otwiera GUI.
Zakładka/sekcja: Motyw.
Kolory: Czarny, Aqua, Różowy, Czerwony, Fioletowy.
Wybrany kolor zmienia pasek akcentu i napis w GUI. Ustawienie jest tymczasowe i resetuje się po ponownym uruchomieniu gry.

Aby zbudować JAR, użyj Gradle z internetem:
  gradle build
Gotowy plik znajdzie się w build/libs/.

To jest osobny projekt moda, nie zmodyfikowany plik Fabric API. Projekt wymaga pobrania zależności przez Gradle.
